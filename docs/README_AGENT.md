# Guide rapide pour les agents IA

## Avant de travailler

1. Lire `00_LIRE_EN PREMIER.md`.
2. Lire `REGLES_COMMUNES.md`.
3. Lire `ETAT_DU_PROJET.md`.
4. Vérifier que ton nom correspond à l'étape active.
5. Lire ton fichier dans `agents/`.
6. Examiner le code existant et les documents pertinents.

## Pendant le travail

- Suivre la mission attribuée.
- Respecter les contrats techniques.
- Vérifier les fichiers avant de les modifier.
- Tester les changements.
- Documenter les limites.
- Ne pas inventer de résultats.
- Ne pas supprimer le travail des autres agents.

## À la fin

1. Fournir un résumé.
2. Lister les fichiers modifiés.
3. Donner les commandes et résultats des tests.
4. Signaler les problèmes restants.
5. Remplir `docs/HANDOFF_TEMPLATE.md` ou en reprendre la structure dans le compte rendu.
6. Mettre à jour `ETAT_DU_PROJET.md`.
7. Indiquer clairement le prochain agent.

## Règle de coordination

Les fichiers Markdown ne transmettent pas automatiquement des informations d'une IA à une autre.

Le dépôt ou dossier partagé doit contenir la dernière version des fichiers et du code.

Un agent ne peut pas savoir qu'une étape est terminée si l'agent précédent n'a pas enregistré et partagé le changement de statut.

## En cas de blocage

Ne pas inventer une solution ni marquer l'étape comme terminée.

Écrire :
- La nature du blocage.
- Les tentatives effectuées.
- Les résultats observés.
- La décision ou l'aide nécessaire.
- Les tâches qui peuvent continuer sans ce point.

## Objectif commun

Livrer un produit réellement utilisable, sécurisé autant que possible, mesurable et documenté dans le délai de 48 heures.
